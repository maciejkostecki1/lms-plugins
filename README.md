# Wtyczki LMS

Prywatne repozytorium trzech wtyczek LMS. Kopia kodu z 23 października 2026 r.

| Katalog | Wtyczka | Wersja |
| --- | --- | --- |
| `plugins/NET24KsefErstePlugin` | Eksport przelewów KSeF do Erste | Brak deklaracji wersji |
| `plugins/LMSNotifyPanelPlugin` | Płatności i blokady | 0.7.4 |
| `plugins/LMSGponHuaweiDemoPlugin` | Huawei GPON DEMO RO | 1.1.0-demo-ro-lite |

Każda wtyczka ma własny README z opisem instalacji. Umieść jej katalog w katalogu `plugins/` LMS i wykonaj instrukcję właściwą dla wtyczki.

Repozytorium zawiera kod i pliki przykładowe. Konfiguracja LMS, hasła, dane klientów, eksporty przelewów i kopie bazy nie są częścią repozytorium.
